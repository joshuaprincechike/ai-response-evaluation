# LLM Response Evaluation

## Evaluation Focus

Evaluation of AI-generated responses for accuracy, completeness, relevance, clarity, reasoning quality, instruction following, and practical usefulness.

## Key Criteria

- Accuracy
- Completeness
- Relevance
- Instruction Following
- Clarity
- Reasoning
- Consistency
- Practical Usefulness

## Evaluation Approach

Responses are reviewed against the requirements of the task. Strengths, weaknesses, omissions, unsupported claims, and inconsistencies are identified before assigning a structured score.

## Example Assessment

A stronger response should address the user's requirements accurately, avoid unsupported conclusions, explain important assumptions, and provide information that is useful for the intended task.

## Skills Demonstrated

AI evaluation, response ranking, rubric-based scoring, critical analysis, error identification, and quality assurance.
